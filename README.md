# ✨ NovaChat — Modern AI Chat Interface

A modern, responsive, and interactive frontend chat application built with **HTML, CSS, and JavaScript**.

NovaChat features a beautiful glassmorphism-inspired UI, animated interactions, chatbot responses, timestamps, and `localStorage` support to preserve conversations even after refreshing the page.

---

## 🚀 Live Preview

Open the project with **VS Code Live Server** to run NovaChat locally.

## 💾 LocalStorage

NovaChat uses the browser's `localStorage` API to save conversations.

Messages remain available even after:

* Refreshing the page
* Closing and reopening the browser
* Restarting the development server

You can remove the saved conversation using the **Clear Conversation** button.
